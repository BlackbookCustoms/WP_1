# Elementor Pro “Badass” Site Build Guide

Use this as a practical blueprint while building in Elementor Pro. It focuses on visual impact, clarity, and conversion.

## 1) Overall Look & Feel
- **Vibe:** Premium, bold, modern, confident.
- **Layout:** Generous spacing, clean grids, strong hierarchy.
- **Motion:** Subtle, purposeful (avoid over-animated clutter).

## 2) Brand Foundation (Set These First)
Define these globally in Elementor:

### Color Palette (4–6 Colors)
- **Primary:** High-contrast brand color (e.g., electric blue, neon green, strong orange)
- **Secondary:** Deep neutral (e.g., #111111, #1B1B1B)
- **Accent:** A pop color for highlights (e.g., #FFCC00)
- **Background:** Off-white or dark mode base
- **Text:** High contrast for readability

### Typography
- **Headings:** Strong sans-serif (e.g., Poppins, Montserrat, Sora)
- **Body:** Clean, readable sans-serif (e.g., Inter, Open Sans)
- **Sizing:**
  - H1: 56–72px
  - H2: 40–52px
  - H3: 28–36px
  - Body: 16–18px

## 3) Homepage Layout (High-Impact Flow)

### Hero Section (Above the Fold)
- **Headline:** 7–10 words max. Clear, bold value proposition.
- **Subheadline:** 1–2 lines of supporting text.
- **CTA Button:** “Get Started” / “Book a Call” / “See Work”.
- **Visual:** High-quality product image, mockup, or video.

### Trust Section
- Add client logos or badges.
- Keep it clean, minimalist grid.

### Features / Services
- 3–6 feature cards
- Use icon + short title + 1–2 sentence description

### Social Proof
- Testimonials with profile images
- Use clean cards with soft shadow

### About / Authority
- Short “Why Us” with key stats or milestones

### Final CTA
- Full-width banner with strong CTA and urgency

## 4) Elementor Pro Enhancements

### Global Theme Style
- Set typography, colors, buttons, spacing globally.

### Motion Effects
- Use:
  - Subtle fade-in or slide-in on scroll
  - Parallax on hero background
  - Hover lift on cards

### Custom Buttons
- Rounded corners or sharp edges depending on vibe
- Hover: invert colors or add glow

### Section Design
- Use diagonal dividers or shape waves between sections
- Alternate background colors for section contrast

## 5) Design Details That Make It “Badass”

✅ Use bold imagery
✅ Strong typographic hierarchy
✅ Consistent spacing (80–120px padding top/bottom)
✅ Minimal clutter
✅ High contrast CTA
✅ 1–2 unique signature design elements (e.g., gradient bar, glow effect)

## 6) Optional Power Moves
- **Sticky header** with CTA
- **Animated numbers** for stats
- **Video hero** (short, looped)
- **Scroll-triggered reveal effects**
